# Stage 6 Execution Requirements

## Step 1 Restrictions

Allowed:
- read existing contracts
- map API boundaries
- create planning documents

Forbidden:
- server deployment
- SSH/Nginx/Docker
- real API calls
- enabling remote access
- database changes
- production code changes
- git commit/push

## Security Boundary

No secrets, tokens, user identifiers, or provider credentials may enter the mini program.
